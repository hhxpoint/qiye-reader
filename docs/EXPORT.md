# 导出设计

栖页把“阅读整理”定义为一份可以带走的个人工作文件，而不是论文的正式译本，也不是新的研究图表。

## 三种格式

| 格式 | 正文 | 图表附录 | 适合 |
| --- | --- | --- | --- |
| PDF | 嵌入式中文字体、分级标题、页码和来源 | 直接复制原 PDF 页面，保留矢量图表与图注 | 交付、打印、长期保存 |
| Word | 原生可编辑文本、页码域、分节 | 1800 px 长边整页 PNG，按原页方向排版 | 继续写作和编辑 |
| Markdown | 纯文本和引用 | 不包含图片 | 归档、检索、二次整理 |

三种格式都可以选择是否包含证据提要、原文与译文、已保存笔记和原页图表附录。未保存的编辑和会话草稿不会进入导出。

## 页面范围

原页附录支持全部页面或用户填写的范围：

```text
1-3,5,8
```

只接受从 1 开始、在文献页数范围内的数字和范围；逗号可以使用英文或中文逗号。输入为空表示全部页面。重复页面会去重并排序。格式错误、越界或起始页大于结束页会在生成前提示。

## PDF

### 版式

- A4 页面，52 pt 版心边距，暖纸色背景。
- 衬线标题和经过约束的正文行宽；正文页有页眉、页脚和整理页码。
- 封面包含标题、作者/来源、年份、导出时间、内容目录和阅读声明。
- 证据、原文译文和笔记按章节排版，保留原文页码和段落编号。
- 人工校订与机器译文使用不同的来源标记；机器译文保留待核对提示。

### 中文字体

导出使用 `public/fonts/QiyeSans-Regular.ttf`。该字体是 Noto Sans SC 的固定字重静态实例，采用 SIL Open Font License 1.1。PDF 导出使用完整字体嵌入，不使用子集化。原因是实际测试中，子集化在部分 CJK 字符上出现了可复制但不可见的问题；完整嵌入会增大文件，但避免静默漏字。

导出前会检查标题、作者、分类、目录、章节、笔记和警告中的字符是否在字体字符表中。遇到不支持的字符会停止导出并提示，不生成缺字文件。

### 原页附录

勾选“保留原论文图表”后，导出会把所选的原始 PDF 页面复制到整理正文之后：

- 页面直接复制，不裁切、不重绘、不改变图表数据。
- 保留原页尺寸和横向/纵向页面。
- 原页不加阅读整理的页眉和页脚，避免遮挡原始信息。
- 原页页码与整理页码是两套编号；导出页会列出原页页码。
- 只选择部分页面时，原 PDF 内部的跨页链接不保证保留。

原 PDF 的页数必须与文献记录一致，否则停止导出。批量 `copyPages` 只调用一次，使多页共享的图片和字体在输出中复用，避免逐页复制导致文件体积成倍增长。

### 大小与失败处理

- 整理正文最多 600 页。
- 输出文件最多 80 MiB。
- 缺原 PDF、页码越界、页数不一致、字体缺字、原页图片无法解码时停止导出。
- 取消发生在当前异步步骤之后；取消后不下载文件，已保存的阅读内容不变。

## Word

Word 导出生成原生 OOXML 文档，正文、标题、引文、提示和页码域可编辑。附录是原 PDF 的整页 PNG，长边 1800 px，放在独立分节中；横向页面使用横向分节，图片等比缩放，不裁切。

附录图片是栅格内容，不是可编辑的表格、矢量图或图表对象。Word 默认字体使用 Calibri 和微软雅黑，未安装时由 Word/WPS 替换；中文字符仍可编辑。导出不请求自动更新所有域，避免打开时触发外部内容提示，也没有外部关系或宏。

Word 导出同样检查：

- 原 PDF 是否存在且页数一致；
- 图片是否真实解码，避免 PDF.js 在图片失败时仍完成渲染并留下白页；
- 原页 PNG 累计不超过 60 MiB；
- 输出文件不超过 80 MiB。

超过限制时提示选择较少页码或分批导出，不静默丢图、不降低图片质量。

## Markdown

Markdown 是轻量文字归档，不包含图片。它保留标题、来源、章节、原文、译文来源、核对提示和笔记，适合复制到其他编辑器或做全文检索。原论文图表请使用 PDF 或 Word 导出，或打开原 PDF 查看。

## 图表为什么按原页保留

直接从 PDF 中自动裁出图表看似更漂亮，但容易漏掉图注、坐标轴、子图、脚注或表格上下文。栖页选择把整页作为附录，并保留来源页码：

- 不把自动裁图冒充完整图表；
- 不翻译或重绘图表内文字；
- 不根据论文数据生成新的图表；
- 读者可以沿原页页码回到原文核对。

如果论文有复杂的跨页图表或双栏版式，原页附录仍是最可靠的保真方式。项目不保证自动识别所有图表边界，也不提供图表 OCR。

## 验收

```sh
npm test
node scripts/with-node.mjs tests/verify-pdf-export.mjs
```

`verify-pdf-export.mjs` 使用仓库内的原创测试 PDF，检查中文可提取、原页逐像素一致、共享图片复用和取消保护。实际 UI 导出还可以使用 `tests/capture-exports.mjs` 在本地回环地址接收浏览器下载，检查文件头和大小；该脚本不进入生产构建。

## 已知边界

- Word 附录图片不可编辑；图表内文字不会被翻译。
- 复杂公式、三栏或特殊编码的 PDF 可能产生解析提示，请以原 PDF 为准。
- 扫描件没有 OCR；没有可信文本时不会伪造摘要。
- 整理正文的页数与 Word/PDF 阅读器、字体和系统有关，导出页码不等于原论文页码。
- 原页附录不保证保留表单、脚本、批注或跨页内部链接。
